# Busstop – Game Rules

## Flow

1. Host starts a game and gets a 4-letter code (no confusing letters like O, I, L).
2. Players join with the code, pick a name and a character.
3. Host sets up the game in the lobby: number of rounds, time per round, and categories.
4. Host presses **Set off**. Every device shows the bus pulling in with the round's letter.
5. Players fill in one answer per category, each starting with that letter.
6. When all fields are filled, **BUSSTOP!** unlocks. Pressing it drops the timer to 10 seconds
   (only if more than 10 are left). The player who called it is named for that round.
7. At 0, all answers lock and are sent in automatically.
8. Scores show on every device. Players can **challenge** answers they think are made up.
9. Host starts the next round. After the last round, the host shows the **final scoreboard**.

## Defaults

- Rounds: 3 (host can pick 3, 5, 8 or 10)
- Timer: 2 minutes
- Categories: Boy's name, Girl's name, Country, Food, Place, Brand
- Extra categories the host can add: Animal, Colour, Fruit or veg, Job, Film or TV show,
  Celebrity, Football team, Car brand, Drink, Sport, Thing in a house, Song – or their own.
  Up to 12 per game.
- Letters: A–Z, skipping hard ones (Q, U, V, X, Y, Z) by default – host can turn them back on

## Scoring (per category)

| How many players gave the same answer | Points each |
| ------------------------------------- | ----------- |
| 1 (unique)                            | 10          |
| 2                                     | 5           |
| 3                                     | 3           |
| 4 or more                             | 2           |
| Blank, wrong letter or challenged out | 0           |

## Challenges

- On the results screen, any player can challenge another player's valid answer (once per
  answer). The challenger's vote counts as "not valid".
- The other connected players (everyone except the challenged player) vote.
- More than half say "not valid" → the answer scores 0 and no longer counts as shared.
  Otherwise the answer stands; a tie goes to the answer.
- A failed challenge costs the challenger nothing.

## End of the game

After the last round – or if the host ends early – everyone sees the final scoreboard: a
podium, and points for every round, marking who called BUSSTOP! each round. Most points wins.

## Assumptions

- Confirmed: 4 or more players sharing an answer = 2 points each.
- Answers match if they are the same after ignoring capitals, spaces, accents and "the"
  (so "The Gap" = "gap").
- The app checks the first letter only; challenges handle made-up words.
